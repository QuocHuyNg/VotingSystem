# VoteChain - Decentralized Voting System

## Tổng Quan
VoteChain là một ứng dụng bầu cử phi tập trung tích hợp Blockchain Sepolia, Node.js và React.

## Khởi Chạy Nhanh
1. **Database**: Đảm bảo file `backend/voting_blockchain.sqlite` tồn tại.
2. **Backend**: 
   - `cd backend`
   - `npm install`
   - `npm run dev`
3. **Frontend**:
   - `cd frontend`
   - `npm install`
   - `npm run dev`
